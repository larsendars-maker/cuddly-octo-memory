# Администраторы OrbitDesk

Файл `admins.json` находится в корне проекта.

Пример:
```json
{
  "admins": [
    "Larsenda",
    "Другой_Admin"
  ]
}
```

Имена сравниваются без учёта регистра. После изменения файла нужен новый deploy на Render. Пользователь, указанный в файле, получает эффективную роль ADMIN.

Для снятия админки сначала убери ник из `admins.json`, затем сделай deploy; после этого роль можно изменить в админ-панели.

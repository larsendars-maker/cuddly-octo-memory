# OrbitDesk v25

- «Часто используешь» теперь показывает только сайты/домены, без поисковых URL и query-параметров.
- Добавлена нормализация доменов и дедупликация частых сайтов.
- Локальные таблицы полностью приведены к интерфейсу мини-табличного редактора: одинаковые ширины столбцов, номера строк, адрес ячейки, строка формул, выделение активной ячейки, Enter/Tab/стрелки для навигации, автосохранение.
- Добавлены понятные кнопки +/− строк и столбцов, удаление таблицы и понятный статус сохранения.
- Карточки быстрых сайтов и информационные блоки выровнены по высоте, добавлены иконки и более компактная сетка.

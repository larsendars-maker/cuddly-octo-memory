# Защищённый вход для HELPER / ADMIN / GL.ADMIN

OrbitDesk теперь требует отдельный служебный пароль после обычного пароля аккаунта для ролей `assistant`, `admin` и `gl.admin`. После успешного ввода сессия получает `privileged_at`, поэтому пароль повторно не спрашивается до выхода из аккаунта/истечения сессии.

## Render
Добавь Environment Variable:

`PRIVILEGED_LOGIN_PASSWORD_HASH`

Готовый hash для стартового пароля из этого релиза:

`scrypt$N=16384,r=8,p=1$25cb916ba4adb9e5463c3e7e7d7a060c$5032d4793dccdf23cdde57654e529524bcc20efab6c22eece9bf358d394510da`

Стартовый пароль: `OrbitDesk-Priv!7Qm#29Lx`

После входа можно оставить его или заменить hash в Render на новый. Не добавляй пароль или hash в GitHub.

## Права
- `GL.ADMIN` — `Larsenda`
- `ADMIN` — обычные администраторы
- `HELPER` — роль `assistant`
- Один успешный ввод служебного пароля разблокирует всю привилегированную часть OrbitDesk для текущей сессии. Повторный ввод для админских действий не нужен.
